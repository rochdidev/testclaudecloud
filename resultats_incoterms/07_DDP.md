# بطاقة عملية: DDP – التسليم مع دفع الرسوم (Delivered Duty Paid)
**الإصدار: Incoterms® 2020 | لجميع وسائل النقل**

## التعريف
يسلّم البائع البضاعة **مخلّصة للاستيراد**، جاهزة للتفريغ على وسيلة النقل الواصلة في المكان المسمى. هي القاعدة التي تفرض **أقصى التزامات على البائع**: كل التكاليف والمخاطر والرسوم الجمركية والضرائب حتى الوجهة.

## التزامات البائع
- تخليص التصدير والعبور **والاستيراد**.
- دفع **الرسوم الجمركية والضرائب** (بما فيها ضريبة القيمة المضافة عند الاستيراد ما لم يُتفق على غير ذلك).
- النقل حتى المكان المسمى وتحمل المخاطر.

## التزامات المشتري
- **التفريغ** في مكان الوجهة.
- مساعدة البائع في الحصول على المستندات والتراخيص.
- استلام البضاعة.

## انتقال المخاطر
عند **وصول البضاعة مخلّصة للاستيراد إلى المكان المسمى، جاهزة للتفريغ**.

## توزيع التكاليف
| البند | البائع | المشتري |
|---|---|---|
| تخليص التصدير والعبور | ✔ | |
| النقل حتى الوجهة | ✔ | |
| تخليص الاستيراد والرسوم والضرائب | ✔ | |
| التأمين | ✔ (اختياري، لمصلحته) | |
| التفريغ | | ✔ |

## نصائح عملية
- تأكد أن البائع **مسموح له قانونيًا** بتخليص الاستيراد في بلد المشتري (قد يتطلب ذلك تسجيلًا ضريبيًا أو ممثلًا جبائيًا).
- احسب بدقة الرسوم والضرائب قبل تقديم السعر.
- إذا أراد الطرفان استثناء ضريبة القيمة المضافة، يُكتب ذلك صراحةً: `DDP… VAT unpaid`.
- مناسبة للتجارة الإلكترونية وللمبيعات للعملاء الذين لا يريدون أي إجراءات.

## أخطاء شائعة
- استعمال DDP في بلد لا يستطيع فيه البائع الأجنبي استرجاع ضريبة القيمة المضافة.
- إغفال رسوم إضافية (مكافحة الإغراق، رسوم المطابقة).

## مثال صياغة
